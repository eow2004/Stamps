# Stamps
## Use cases and usage
This code is primarily best used when making cutouts of objects in a single field of view. When wanting to specify and iterate through a number of objects visible in different frames of view, using some of my past work [(DeconvolutionStamps)](https://github.com/eow2004/DeconvolutionStamps) might be better. There may be a use case when I need to update this code to incorperate that workflow, but that is a later issue.
